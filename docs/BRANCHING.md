# Branches

## Branches principales

- `main` : version stable du projet.
- `develop` : branche sur laquelle les nouvelles fonctionnalités sont intégrées avant d'être ajoutées à main.

## Créer une branche

- feature/ : nouvelle fonctionnalité
- fix/ : correction d'un bug
- hotfix/ : correction urgente sur main
- docs/ : documentation
- test/ : tests
- refactor/ : modification du code sans changement de comportement

## Règles de nommage des commits

- feat : ajout d'une fonctionnalité.
- fix : correction d'un bug.
- refactor : modification du code sans changement de comportement.
- test : ajout ou modification de tests.
- docs : modification de documentation.
- chore : maintenance et configuration du projet.
- build : modification du système de build ou des dépendances.
- ci : modification de l'intégration continue.
- perf : amélioration des performances.
- style : modification du formatage sans changement de logique.

## Règles de nommage

- Utiliser uniquement des minuscules.
- Séparer les mots par des tirets.
- Ne pas utiliser d'espaces ou d'accents.
- Choisir des descriptions courtes et explicites.
